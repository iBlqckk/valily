# Dragon Heart Chronicle

Crea una página web de una sola página (landing page) tipo "carta de amor digital" con temática dark romance / romantasy, inspirada en el mundo de fantasía con dragones y academias militares (estilo "romantasy" oscuro). El objetivo es ser un regalo romántico personalizado para mi pareja.

ESTÉTICA VISUAL:

- Paleta de colores: negro profundo, granate/vino tinto, dorado envejecido/bronce como acento, y toques de blanco hueso para contraste

- Fondo con textura sutil tipo pergamino oscuro, humo, o escamas de dragón (usar gradientes/CSS, sin imágenes con copyright)

- Tipografía: una fuente serif elegante y gótica para títulos (tipo Cinzel, Cormorant Garamond o UnifrakturMaguntia) y una sans-serif limpia para texto de lectura

- Elementos decorativos: siluetas de alas, dragones minimalistas en línea dorada, ornamentos tipo grabado antiguo, brillos/partículas sutiles tipo "polvo dorado" en el fondo

- Animaciones suaves al hacer scroll (fade-in, parallax ligero), transiciones elegantes, nada abrupto

ESTRUCTURA DE SECCIONES:

1. HERO / PORTADA

- Pantalla completa, fondo oscuro con animación sutil de partículas doradas

- Título grande: "[NOMBRE DE ELLA]" o una frase corta tipo "Mi elegida" / "Mi jinete de dragón"

- Subtítulo con una frase romántica corta escrita por mí (dejar placeholder de texto editable)

- Botón que invita a "Comenzar nuestra historia" que hace scroll a la siguiente sección

2. NUESTRA HISTORIA (timeline)

- Línea de tiempo vertical elegante con 2024 como punto de partida

- Tarjetas con fecha + texto corto para momentos importantes (dejar placeholders: "El día que nos conocimos", "El día que todo cambió", etc.)

- Iconos pequeños tipo alas o llamas separando cada evento

3. CARTA PARA ELLA

- Sección tipo "pergamino" o carta antigua con borde ornamentado dorado

- Espacio de texto largo para una carta personal (dejar placeholder de párrafos)

- Efecto visual de "sello de cera" o firma al final

4. GALERÍA DE MOMENTOS

- Grid de fotos con marco oscuro elegante y hover effect (leve brillo dorado al pasar el mouse)

- Placeholders de imágenes para que yo las reemplace después

5. "POR QUÉ ERES MI HOGAR" / RAZONES

- Grid o carrusel de tarjetas con pequeñas frases sobre por qué la amo

- Cada tarjeta con ícono decorativo (ala, corazón con espada, luna)

6. CIERRE / DEDICATORIA FINAL

- Frase final grande y emotiva

- Fondo oscuro con animación de partículas doradas cayendo lentamente

- Firma con mi nombre y fecha

FUNCIONALIDAD:

- Totalmente responsive (que se vea perfecto en celular)

- Scroll suave entre secciones

- Modo oscuro por defecto (no necesita modo claro)

- Opcional: reproductor de música
